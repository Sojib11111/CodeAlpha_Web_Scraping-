# 🏦 End-to-End Analysis of US Failed Banks Using Web Scraping and Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on analyzing the US Failed Banks dataset using **Web Scraping, Data Cleaning, Exploratory Data Analysis (EDA), and Data Visualization** techniques.  
The goal is to understand patterns behind bank failures, identify high-risk states, analyze financial losses, and explore trends over time.

---

## 🎯 Objectives
- Collect or extract failed bank data (Web Scraping / Dataset)
- Clean and preprocess the dataset
- Perform exploratory data analysis (EDA)
- Identify patterns in bank failures
- Visualize insights using charts and graphs
- Understand financial risk trends in the banking sector

---

## 🛠️ Tools & Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Web Scraping (BeautifulSoup / Requests)

---

## 📊 Dataset Information
The dataset contains information about failed banks in the United States with the following features:

- Bank Name
- City
- State
- Cert
- Acquiring Institution
- Closing Date
- Fund Loss

---

## 🔍 Key Analysis Performed

### 📌 1. State-wise Bank Failures
Identified which US states have the highest number of failed banks.

### 📌 2. Year-wise Trend Analysis
Analyzed bank failures over different years to observe financial crisis patterns.

### 📌 3. Acquiring Institution Analysis
Found which banks acquired the most failed banks.

### 📌 4. Fund Loss Analysis
Calculated total and state-wise financial losses.

---

## 📈 Data Visualization
The following visualizations were created:
- Bar chart of top states with most bank failures
- Line chart of yearly bank failures
- Bar chart of top acquiring institutions
- Histogram of fund loss distribution
- Heatmap for missing values

---

## 📷 Sample Insights
- Certain states experienced significantly higher bank failure rates.
- Bank failures peaked during financial crisis periods.
- A few large banks acquired most of the failed banks.
- Financial loss distribution is highly skewed.
